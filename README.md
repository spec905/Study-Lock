# Study-Lock
A web app that helps students plan revison and stay focused

Study Lock lets you save multiple exams,build a realistic study schedule,track topics and run timed focus sessions.Everything is saved in the browser,so your plans and history stay even after you close the page
# Features
1.Exam planning
.save multiple exams(name,date and topics)
.choose how many study days per week (3to7)
.Generate a realistic schedule(spaced sessions+review days)
.check off tasks as you complete them
.see today's tasks and days left until the exam
2.Focus sessions
.time lock mode:30min,60min,open session
.optional music(Spotify/youtube link,saved+can change the account at any time)
